# AI-SDN-SIEM

## Overview
A lightweight AI-driven SIEM framework for Software-Defined Networks using CNN-BiLSTM for attack detection and automated mitigation via SDN controllers.

## Components
- SDN Controller: Ryu
- AI Engine: CNN-BiLSTM (TensorFlow Lite)
- SIEM: Fluent Bit + OpenSearch
- Visualization: OpenSearch Dashboards
- Traffic Generator: Mininet

## Features
- Real-time flow monitoring
- AI-based attack detection
- Automated OpenFlow mitigation
- SIEM logging and dashboards
